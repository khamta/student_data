# ລະບົບຈັດການຂໍ້ມູນນັກສຶກສາ (ระบบจัดการข้อมูลนักศึกษา)

เว็บแอปฟรีสำหรับจัดการข้อมูลทำเนียบนักศึกษาที่สำเร็จการศึกษา ตามรูปแบบรายงานที่แนบมา —
เพิ่ม/แก้ไข/ลบข้อมูลนักศึกษา, จัดการหมวดหมู่/สาขาวิชา, อัปโหลดรูปภาพ, และสร้างรายงาน
พร้อมพิมพ์ที่จัดกลุ่มตามสาขาวิชาพร้อมสรุปจำนวนชาย/หญิงอัตโนมัติ ตรงตามรูปแบบชีตเดิมของคุณ

ระบบนี้สร้างด้วย **Google Apps Script web app ที่ผูกกับ Google ชีตโดยตรง**
ซึ่งหมายความว่า:

- **ฟรี 100%** — โฮสต์โดย Google ที่ `script.google.com` ไม่ต้องมีเซิร์ฟเวอร์แยก
  ไม่ต้องผูกบัตรเครดิต ไม่มีวันหมดอายุทดลองใช้
- **ข้อมูลอยู่ใน Google ชีตปกติที่คุณเป็นเจ้าของ** เปิดดูตรงๆ, สำรองข้อมูล,
  หรือส่งออกได้ตลอดเวลา
- **ไม่ต้องจัดการ API key หรือ service account ใดๆ** — แอปทำงานภายใต้สิทธิ์
  บัญชี Google ของคุณเอง

## ไฟล์ในโปรเจกต์

ต้องคัดลอกไปวางใน Apps Script แค่ **2 ไฟล์** เท่านั้น:

| ไฟล์               | หน้าที่                                                        |
|--------------------|-----------------------------------------------------------------|
| `Code.gs`          | โค้ดฝั่งเซิร์ฟเวอร์: ตั้งค่าชีต, CRUD ข้อมูล, อัปโหลดรูป, ข้อมูลรายงาน |
| `Index.html`       | หน้าตาแอปทั้งหมด — HTML, CSS และ JavaScript รวมอยู่ในไฟล์เดียว    |

ส่วน `appsscript.json` แนบไว้เพื่ออ้างอิง/สำหรับดีพลอยผ่าน `clasp` เท่านั้น
**ไม่จำเป็นต้องเปิดหรือแก้ไข** — Apps Script จะตรวจจับสิทธิ์ที่ต้องใช้
(Sheets + Drive) ให้อัตโนมัติตั้งแต่รันครั้งแรก

ข้อมูลจะถูกเก็บใน 3 ชีต ซึ่งจะถูกสร้างขึ้นอัตโนมัติตอนรันแอปครั้งแรก:

- **Students** — ข้อมูลนักศึกษา 1 แถวต่อ 1 คน (ทุกฟิลด์จากฟอร์ม)
- **Categories** — หัวข้อกลุ่ม "I. ...", "II. ..." / สาขาวิชา
- **Settings** — ข้อความหัวกระดาษและชื่อเรื่องที่แสดงบนรายงานที่พิมพ์

โครงสร้างคอลัมน์ หัวตาราง (ที่มีการรวมเซลล์แบบ "ເລກທະບຽນນັກສຶກສາ" /
"ທະບຽນທາງວິທະຍາໄລ" / "ໃບປະກາດມ.ປາຍ"), ชื่อ 4 หมวดหมู่ (I–IV), และแถวสรุป
ท้ายรายงาน ถอดแบบมาให้ตรงกับไฟล์ต้นฉบับ (PDF ที่ export จาก Google ชีตจริง)
ทุกตัวอักษร — รวมถึงข้อมูลนักศึกษาทั้ง 39 คนจากไฟล์ต้นฉบับที่ใส่เป็นข้อมูล
เริ่มต้นให้เลย (ลบ/แก้ไขได้ตามปกติจากแท็บ "ລາຍຊື່ນັກສຶກສາ")

## วิธีดีพลอยเชื่อมกับ Google ชีตของจริงที่มีอยู่แล้ว (ใช้เวลาประมาณ 3 นาที)

แอปนี้ทำงานโดย **ผูกสคริปต์เข้ากับชีตที่เปิด Extensions → Apps Script
ขึ้นมาโดยตรง** (ใช้ `SpreadsheetApp.getActiveSpreadsheet()`) จึงต้อง
เปิด Apps Script **จากในชีตจริงที่มีข้อมูลของคุณอยู่แล้ว** ไม่ใช่สร้างชีตใหม่
ขั้นตอนสุดท้ายนี้ต้องทำจาก **บัญชี Google ของคุณเอง** เท่านั้น — การดีพลอย
โปรเจกต์ Apps Script ต้องกดปุ่ม "Authorize" ด้วยตัวคุณเอง ซึ่งไม่มีใคร
(รวมถึง AI ผู้ช่วย) ทำแทนได้ แต่ขั้นตอนไม่ยุ่งยาก:

### วิธีที่ 1 — คัดลอกไปวางใน Apps Script Editor (ง่ายที่สุด, แนะนำ)

1. เปิด **ชีตจริงของคุณ** ที่มีข้อมูลนักศึกษาอยู่แล้ว:
   https://docs.google.com/spreadsheets/d/1hc-O6z_pNna_E6T_KgHakbQ841EatuU9lt4209W06gE/edit?gid=0#gid=0
2. ในชีตนั้น เปิด **Extensions → Apps Script** (จะได้โปรเจกต์สคริปต์ที่ผูก
   กับชีตนี้โดยตรง)
3. ในหน้าตัวแก้ไข (editor):
   - เปิดไฟล์ `Code.gs` (ไฟล์เริ่มต้น) ลบทุกอย่างในนั้นออก แล้วคัดลอกเนื้อหา
     จากไฟล์ [`Code.gs`](./Code.gs) ของโปรเจกต์นี้ไปวาง แล้วกด Save (Ctrl/Cmd+S)
   - กด `+` ข้างคำว่า **Files** → เลือก **HTML** → ตั้งชื่อไฟล์ใหม่ว่า
     `Index` (ต้องตรงเป๊ะ) → ลบเนื้อหาตัวอย่างออกแล้วคัดลอกเนื้อหาจากไฟล์
     [`Index.html`](./Index.html) ไปวาง แล้ว Save
4. กด **Deploy → New deployment**
   - กดไอคอนรูปเฟืองข้างคำว่า "Select type" → เลือก **Web app**
   - Execute as: **Me**
   - Who has access: เลือก **Anyone** (เป็นลิงก์สาธารณะเต็มรูปแบบ) หรือ
     **Anyone with a Google account** ถ้าต้องการให้ล็อกอินก่อนเข้าใช้งาน
   - กด **Deploy** จากนั้นกด **Authorize access** แล้วกดยอมรับสิทธิ์ที่ขึ้นมา
     (เป็นสคริปต์ของคุณเองที่ขอสิทธิ์แก้ไขชีต/ไดรฟ์ของคุณเอง ปลอดภัยที่จะกดยอมรับ)
5. คัดลอก **Web app URL** ที่ปรากฏขึ้นมา — นี่คือลิงก์แอปที่ใช้งานได้จริง
   เปิดลิงก์นี้ครั้งแรก ระบบจะตรวจสอบชีต `Students`/`Categories`/`Settings`
   ในไฟล์เดียวกันนี้ — ถ้ายังไม่มี จะสร้างให้อัตโนมัติพร้อมข้อมูลตั้งต้น
   (39 คนจาก PDF ต้นฉบับ) ถ้ามีอยู่แล้วจะ**อ่าน/แก้ไขข้อมูลจริงในนั้นทันที**
   ไม่แตะข้อมูลเดิมที่ไม่เกี่ยวข้อง

เท่านี้ก็เสร็จ — แอปพร้อมใช้งานจริง เชื่อมกับชีตจริงของคุณ ฟรี และเป็นของคุณเอง
บันทึกลิงก์ Web app URL ไว้ หรือเข้าไปที่ชีตแล้วใช้เมนู
**Extensions → ⁠ລະບົບຈັດການນັກສຶກສາ → ເປີດຄູ່ມືການນຳໃຊ້** เป็นตัวเตือนว่าจะหา
ลิงก์ได้จากที่ไหน

ถ้าในอนาคตต้องการแก้ไขโค้ดเพิ่มเติม แค่เข้า **Deploy → Manage deployments
→ ✏️ (แก้ไข) → New version → Deploy** เพื่ออัปเดตแอปที่ลิงก์เดิมได้เลย

### วิธีที่ 2 — ดีพลอยผ่าน `clasp` (สำหรับผู้ที่ถนัด command line)

**สำคัญ:** ห้ามใช้ `clasp create --type sheets` เพราะจะสร้าง **ชีตใหม่เปล่าๆ**
ขึ้นมาแยกต่างหาก ไม่ใช่ชีตจริงที่มีข้อมูลอยู่แล้ว ต้อง**ผูกกับโปรเจกต์สคริปต์
ที่มาจากชีตจริงเท่านั้น**:

1. เปิดใช้งาน **Google Apps Script API** ของบัญชีคุณก่อน (ทำครั้งเดียว) ที่
   https://script.google.com/home/usersettings — เปิดสวิตช์ "Google Apps
   Script API" ให้เป็น ON แล้วรอสัก 1-2 นาทีให้ระบบ sync
2. เปิด **ชีตจริงของคุณ** → **Extensions → Apps Script** เพื่อสร้างโปรเจกต์
   สคริปต์ที่ผูกกับชีตนี้ (ถ้ายังไม่เคยเปิดมาก่อน)
3. ในหน้า Apps Script editor กด **Project Settings** (ไอคอนเฟือง) แล้วคัดลอก
   **Script ID** ที่แสดงอยู่
4. กลับมาที่เครื่อง รันคำสั่ง:
   ```bash
   npm install -g @google/clasp
   clasp login
   clasp clone <SCRIPT_ID_ที่คัดลอกมา> --rootDir .
   ```
   คำสั่งนี้จะดึงโปรเจกต์ที่ผูกกับชีตจริงมาไว้ในโฟลเดอร์นี้ (สร้างไฟล์
   `.clasp.json` ให้อัตโนมัติ — ไฟล์นี้ถูกใส่ไว้ใน `.gitignore` แล้ว)
5. คัดลอก [`Code.gs`](./Code.gs) และ [`Index.html`](./Index.html) ของ
   โปรเจกต์นี้ทับไฟล์ที่ clone มา แล้ว push และ deploy:
   ```bash
   clasp push
   clasp deploy --description "v1"
   ```
   ถ้า `clasp push` ถามยืนยัน overwrite ให้ตอบ yes

หลัง `clasp deploy` แล้ว ดูลิงก์ Web app ได้จากคำสั่ง `clasp deployments`
หรือจากเมนู **Deploy → Manage deployments** ใน Apps Script editor (เปิดด้วย
`clasp open`) — ต้องกด **Authorize access** ในหน้าเว็บด้วยตัวเองอย่างน้อย
หนึ่งครั้งเพื่อยืนยันสิทธิ์เข้าถึงชีต/ไดรฟ์ของคุณ

## วิธีใช้งานแอป

- **ລາຍຊື່ນັກສຶກສາ (รายชื่อนักศึกษา)** — ค้นหา/กรอง, เพิ่ม, แก้ไข, ลบข้อมูล
  นักศึกษา รูปภาพจะถูกอัปโหลดเข้าโฟลเดอร์ Google Drive ชื่อ
  `StudentPhotos_DoNotDelete` และเชื่อมลิงก์กลับเข้าชีตให้อัตโนมัติ ช่อง
  "ສາຂາວິຊາ" เป็น dropdown ที่ตรึงไว้แค่ 4 สาขาตามจริง (ບໍລິຫານທຸລະກິດ,
  ວິທະຍາສາດຄອມພິວເຕີ ແລະ ຂໍ້ມູນຂ່າວສານ(ໄອທີ), ພາສາອັງກິດທຸລະກິດ,
  ການເງິນ-ການບັນຊີ) เลือกแล้วชื่อวิชาภาษาอังกฤษ (Major) จะถูกตั้งค่าให้ตรงกัน
  โดยอัตโนมัติ ไม่มีหน้าจัดการหมวดหมู่แยกต่างหากอีกต่อไป นอกจากรูปนักศึกษา
  แล้วยังอัปโหลด **รูปใบประกาศ** แนบต่อคนได้ด้วย และแต่ละแถวมีปุ่ม
  "ລາຍລະອຽດ" เปิดหน้าต่างสรุปข้อมูลทั้งหมดของนักศึกษาคนนั้นแบบอ่านอย่างเดียว
  (พร้อมรูปทั้งสอง) ก่อนค่อยกด "ແກ້ໄຂ" ต่อจากหน้าต่างเดียวกันได้เลยถ้าต้องการ
- **ຕັ້ງຄ່າຫົວບົດລາຍງານ (ตั้งค่าหัวรายงาน)** — แก้ไขข้อความหัวกระดาษองค์กร,
  ชื่อเรื่องรายงาน, และคำบรรยายช่องลายเซ็นที่แสดงบนรายงานที่พิมพ์
- **ພິມ / ອອກລາຍງານ (พิมพ์/ออกรายงาน)** — แสดงรายงานฉบับเต็มจัดกลุ่มตาม
  หมวดหมู่ พร้อมสรุปจำนวนชาย/หญิงทั้งรายกลุ่มและรวมทั้งหมด ตรงตามรูปแบบเดิม
  กดปุ่ม **🖨️ ພິມ / ບັນທຶກເປັນ PDF** แล้วเลือก "Save as PDF" ในหน้าต่างพิมพ์
  ของเบราว์เซอร์เพื่อส่งออกเป็น PDF ได้เลย ไม่ต้องพึ่งบริการเสริมใดๆ

  นอกจากนี้ยังมีแท็บ **`ລາຍງານພິມ`** ในไฟล์ Google ชีตของคุณโดยตรง จัดวาง
  เหมือนหน้ารายงานที่พิมพ์ทุกอย่าง (หัวกระดาษ, หัวตารางแบบรวมเซลล์, จัดกลุ่ม
  ตามสาขา, แถวสรุป, บรรทัดลงนาม) — **อัปเดตให้อัตโนมัติแบบเรียลไทม์** ทุกครั้ง
  ที่มีการเพิ่ม/แก้ไข/ลบนักศึกษา หรือแก้ไขหัวรายงานผ่านเว็บแอป และยังอัปเดต
  อัตโนมัติด้วยถ้ามีคนแก้ไขข้อมูลตรงในชีต `Students`/`Categories`/`Settings`
  โดยตรงเช่นกัน (ผ่าน `onEdit` trigger) เปิดแท็บนี้ดูตรงๆ หรือแชร์ให้คนอื่นที่
  ไม่ได้เข้าเว็บแอปก็ได้เลย ไม่ต้องกดปุ่มอะไรเพิ่ม
  ถ้าต้องการบังคับให้อัปเดตใหม่ด้วยตัวเอง (เช่นหลังแก้ไขข้อมูลจำนวนมาก)
  กดปุ่ม **📄 ອັບເດດລົງ Google Sheet** ในแท็บพิมพ์รายงาน หรือเมนู
  **Extensions → ⁠ລະບົບຈັດການນັກສຶກສາ → ອັບເດດຊີດລາຍງານພິມ** ในชีตได้เช่นกัน
  หมายเหตุ: การตั้งค่าขนาดกระดาษ A4 แนวนอนตอนพิมพ์ต้องเลือกเองจากเมนู
  File → Print ของ Google ชีต เนื่องจาก Apps Script ไม่มี API ให้ตั้งค่านี้
  ล่วงหน้าให้อัตโนมัติ

## หมายเหตุและการปรับแต่งเพิ่มเติม

- รูปภาพจะถูกตั้งค่าแชร์แบบ "ทุกคนที่มีลิงก์สามารถดูได้" เพื่อให้แสดงผลใน
  แอป/รายงานได้ หากมีข้อกังวลเรื่องความเป็นส่วนตัว ไม่ควรอัปโหลดรูปที่
  เป็นข้อมูลอ่อนไหว
- ข้อความในแถวสรุป/ชื่อเรื่องต่างๆ สามารถปรับแก้ได้ตลอดเวลาจากแท็บ
  **Settings** โดยไม่ต้องแก้โค้ด
- เนื่องจากแอปผูกกับ Google ชีตของคุณโดยตรง คุณ (หรือผู้ที่คุณแชร์สิทธิ์
  แก้ไขให้) สามารถเปิดชีตดิบเพื่อแก้ไขข้อมูลจำนวนมากได้โดยตรง และเว็บแอป
  จะแสดงผลข้อมูลที่อัปเดตในการโหลดครั้งถัดไป
- หากต้องการจำกัดผู้ใช้งาน ให้ดีพลอยใหม่โดยเลือก **Who has access →
  Anyone with a Google account** หรือ **Only myself** จากเมนู
  **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ)**
